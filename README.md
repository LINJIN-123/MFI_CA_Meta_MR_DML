## 1. Project overview

This repository contains the complete, reproducible analysis code supporting the manuscript
**"Genetic Association Between Male Factor Infertility and Cancers: A Meta-Analysis,
Bidirectional Two-Sample Mendelian Randomization and Double Machine Learning"** (Jin Lin,
Xiu Gao, Wei Chen). It covers three complementary components:

1. A **meta-analysis** of adjusted hazard ratios (aHR) from published observational cohort studies
   (overall pooled estimate, heterogeneity, leave-one-out, publication bias, subgroup analysis with
   cluster-robust variance estimation).
2. **Bidirectional two-sample Mendelian randomization (2SMR)** between male factor infertility
   traits (male infertility; abnormal spermatozoa) and 13 common cancers, using the OpenGWAS
   online API, with sensitivity analyses, Benjamini–Hochberg FDR correction and minimum
   detectable odds ratio (MDOR) calculations.
3. **Summary-level double machine learning (DML)** with cross-fitting (LassoCV primary learner;
   random forest sensitivity learner).

All statistical estimates reported in the manuscript are generated by the scripts in this
repository. No manual copy-and-paste of results is required.

## 3. Data sources and access

- **GWAS summary statistics** are obtained online through the
  [OpenGWAS API](https://gwas.mrcieu.ac.uk/) using `TwoSampleMR` and `ieugwasr`.
  Cancer datasets are from the IEU OpenGWAS Project; the male infertility and abnormal
  spermatozoa datasets are from FinnGen.
- **Raw GWAS files are intentionally NOT stored in this repository** because of their size and
  data-use terms. The scripts retrieve the required data automatically via the API. If a FinnGen
  endpoint cannot be read online, the corresponding local FinnGen file may be used solely as the
  outcome; see `docs/run_instruction.md`.
- The **OpenGWAS access token is never hard-coded**. Set it as an environment variable
  (`OPENGWAS_TOKEN`); the scripts read it at run time.
- The small observational meta-analysis input table (`数据提取.xlsx` / a CSV equivalent) is
  documented in `docs/run_instruction.md`.

## 4. Reproduction at a glance

- R: install R ≥ 4.x, open the project, restore the locked environment with `renv`, then run the
  numbered scripts in order. Full details: `docs/run_instruction.md`.
- Python: install Anaconda/Miniconda, create the environment from `environment.yml`, then run the
  two scripts in `Python_DML/`.

Detailed, beginner-friendly steps (including copy-paste commands) are provided in
[`docs/run_instruction.md`](docs/run_instruction.md).
