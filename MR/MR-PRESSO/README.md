# MR‑PRESSO Sensitivity Analysis — R Source Scripts

This folder contains the R source code used to perform **MR‑PRESSO sensitivity
analysis** as part of the bidirectional two-sample Mendelian randomization (2SMR)
component of this project. It complements the main 2SMR scripts in
[`../../R_analysis/`](../../R_analysis/): whereas `R_analysis/` covers the
primary IVW/weighted-median/MR-Egger estimates, FDR correction and MDOR power
calculation, this folder adds **MR‑PRESSO outlier detection and global
heterogeneity testing** for the same bidirectional trait–cancer pairs.

MR‑PRESSO (Mendelian Randomization Pleiotropy RESidual Sum and Outlier) is used
here purely as a **robustness / pleiotropy-sensitivity check**; it does not
replace the primary IVW estimate. All results reported in the manuscript that
derive from this module are generated by running the scripts below.

> **Scope.** This directory contains **source code only**. Result tables
> (`.csv`), run logs and the `output/` folder are intentionally excluded from
> version control (see the repository root `.gitignore`). No generated results
> are stored here.

---

## 1. Analysis design

- **Traits (exposures/outcomes):** two male-reproductive traits — `Male infertility`
  (FinnGen R12, `finngen_R12_N14_MALEINFERT`) and `Abnormal spermatozoa`
  (FinnGen R5, `finngen_R5_R18_ABNORMAL_SPERMATOZ`).
- **Cancers:** 32 cancer GWAS datasets (colon, colorectal, liver, oesophagus,
  gastric, bladder, prostate, testicular, leukaemia, non‑Hodgkin lymphoma,
  Hodgkin lymphoma, melanoma, thyroid) retrieved online from OpenGWAS.
- **Directions:** bidirectional — forward (trait → cancer) and reverse
  (cancer → trait) — giving 2 × 32 × 2 = **128 trait–cancer analyses**.
- **Instrument / QC parameters (identical to the manuscript main analysis):**
  - Instrument selection: `p1 = 1e-5`
  - LD clumping: `r² = 0.001`, `kb = 10000`
  - Harmonisation: `action = 2`
  - Exclude palindromic SNPs; exclude `MAF < 0.01`
  - MR‑PRESSO: `NbDistribution = 1000`, `SignifThreshold = 0.05`, `set.seed(1234)`
- **Reproducibility:** a fixed random seed (`1234`) is set before every
  MR‑PRESSO run so the simulated p‑values are fully reproducible. Every pair is
  wrapped in error handling; a failed pair (insufficient SNPs / API error /
  package error) is skipped and recorded without aborting the loop.

## 2. File inventory

| File | Purpose |
| --- | --- |
| `check_env.R` | Environment sanity check: R version, required packages (`TwoSampleMR`, `MRPRESSO`, `data.table`, `ieugwasr`, `dplyr`), and OpenGWAS token presence. |
| `inspect_headers.R` | Reads the two local FinnGen files to print their column headers and tests OpenGWAS connectivity (`gwasinfo` / small `extract_outcome_data`). |
| `inspect_presso.R` | Prints the `MRPRESSO::mr_presso` function signature and the first part of its body (used to confirm the local package API). |
| `inspect_presso2.R` | Prints the remainder of the `mr_presso` function body (helper for the API inspection in `inspect_presso.R`). |
| `run_bidirectional_MR_PRESSO.R` | **Main script.** Runs the full bidirectional MR‑PRESSO analysis across all 128 trait–cancer pairs, with caching, per‑pair error handling and progress checkpointing. |
| `resume_MR_PRESSO.R` | **Resume script.** Reads the progress checkpoint, rebuilds the canonical 128‑pair plan, skips already‑completed pairs (keyed by `Exposure_ID \| Outcome_ID`) and runs only the missing ones, then merges and writes the final table. |
| `smoke_test.R` | Quick smoke test on a single trait × single cancer × both directions to validate function signatures and result structure before running the full job. |

**Recommended run order:** `check_env.R` → `inspect_headers.R` (optional API
check) → `run_bidirectional_MR_PRESSO.R` (full run; use `resume_MR_PRESSO.R` if
the process was interrupted) → `smoke_test.R` (optional). The `inspect_presso*.R`
scripts are diagnostic helpers and are not required for the analysis itself.

## 3. Requirements

- **R** ≥ 4.x
- **R packages:** `TwoSampleMR`, `MRPRESSO`, `data.table`, `ieugwasr`, `dplyr`
- **OpenGWAS access token** (for online cancer data retrieval)
- **Local FinnGen summary statistics** for the two reproductive traits
  (`finngen_R12_N14_MALEINFERT`, `finngen_R5_R18_ABNORMAL_SPERMATOZ`), obtained
  from FinnGen under their data‑use terms. Raw GWAS files are **not** included
  in this repository.

## 4. Configuration before running

The scripts were developed in a specific local environment, so two things must
be adjusted to your own setup:

1. **OpenGWAS token (required).** The token is **never hard‑coded**. Each script
   reads it from the `OPENGWAS_JWT` environment variable:

   ```r
   Sys.setenv(OPENGWAS_JWT = "<your OpenGWAS JWT>")
   ```

   or add `OPENGWAS_JWT=<your token>` to your `~/.Renviron` (recommended, so it
   is reused across sessions and never committed).

2. **Local paths.** The scripts reference absolute local paths for the working
   directory, the two FinnGen `.gz` files, and the result export location
   (variables such as `script_dir`, `trait_map$file_path`, `final_csv`,
   `out_dir`). Edit these to match your machine before running.

The two FinnGen files are read with automatic detection of the effect‑allele
frequency column (`af_alt` for R12, `maf` for R5); rsIDs are cleaned (first ID
kept, placeholders/duplicates removed) and standardised to TwoSampleMR fields.

---

## 5. Outputs (not tracked)

When run, the scripts write result tables and logs to the paths configured in
the scripts (`output/`, the progress checkpoint CSV, and a final results CSV).
These are **generated artifacts** and are excluded from version control by the
root `.gitignore`; only the source code in this folder is versioned.
